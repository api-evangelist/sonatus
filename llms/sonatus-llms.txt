# Sonatus

> Sonatus, Inc. is an automotive software company in Sunnyvale, California, founded in 2018,
> building cloud-to-edge vehicle AI software for software-defined vehicles (SDVs). Sonatus sells
> to vehicle OEMs and tier-one suppliers under commercial agreement. It has NO public developer
> program, NO public API reference, and NO machine-readable API contract.

## What Sonatus builds

- Fastlane Platform: an AI-orchestrated observe / analyze / act / learn cycle spanning cloud and
  vehicle edge, portable across public or private cloud providers.
- Fastlane Edge: in-vehicle AI deployment and edge processing.
- Fastlane Collector: generative-AI-assisted authoring of dynamic vehicle data-collection policies,
  deployable in real time to vehicles at any lifecycle stage.
- Fastlane Insight: cloud-side analysis of collected vehicle data using large language models.
- Fastlane Copilot: quick-start integration package.
- Sonatus Automator: vehicle automation, and the basis of the Vehicle Personalization Solution.

Sonatus states its technology is deployed in more than eight million vehicles. Investors and
strategic backers include Hyundai Motor Group, Kia, LG, Marvell, NEC, Foxconn and Translink Capital.

## API surface — read this before looking for one

Sonatus markets an SDK. Its December 2023 Vehicle Personalization Solution announcement describes
"an SDK comprising Sonatus Automator, APIs, and documentation" for OEMs building personalization
apps for smartphone, IVI and web surfaces. That SDK and its reference are delivered to contracted
OEM customers only.

  reach it.
- developer.sonatus.com, api.sonatus.com, developers.sonatus.com, portal.sonatus.com,
  cloud.sonatus.com, app.sonatus.com, console.sonatus.com — no DNS record.
- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, gRPC .proto or WSDL is published at any Sonatus host.
- No /.well-known document is served by any Sonatus host (404 on www, 403 on docs).
- No MCP server and no A2A agent card.
- No first-party package in npm, PyPI or any other public registry. The public GitHub organization
  github.com/sonatus holds 17 repositories, all of which are forks of upstream open-source projects.

An agent cannot integrate with Sonatus today. The correct next step is a commercial conversation
via https://www.sonatus.com/contact/, not an API key.
